# 今日のポケGOイベント

ポケモンGOで「今日なにが開催されているか」を一目で確認するための、1ページだけのWebアプリです（非公式）。

## できること
- **今日のおトク（ボーナス）** を画面上部にまとめて表示（ほしのすな・アメ・XPの倍率、レイドパス、タマゴの距離、マックス粒子など）。GOパスの達成が必要なもの・有料のものには印付き
- **今日の時間限定イベント**（レイドアワー、スポットライトアワー、コミュニティ・デイなど）を、開始・終了までの残り時間付きで表示
- **開催中のイベント・レイドボス**（★5／メガ／シャドウレイドのボス、色違いの有無 ✨）
- **今日まで／今日から** の目印
- 上の日付タブで **明日以降（7日先まで）** に切り替え
- **このあと7日間の時間限定イベント** の一覧（タップでその日へ移動）
- シーズン・GOパス・GOバトルリーグなどの長期のものは折りたたみ
- 30秒ごとに残り時間を更新、30分ごとにデータを再取得。前回取得したデータは端末に保存されるので、通信できないときも前回分を表示

## ページ
- `index.html`：今日のイベント（ボーナス、時間限定イベント、レイドなど）。コミュニティ・デイやレイドなどのカードに「アメを増やすのにおすすめのメガシンカ」（捕まえるポケモンと同じタイプのメガ）を表示
- `research.html`：フィールドリサーチ一覧（今ポケストップで出るタスクと、もらえるポケモン・アイテム。ポケモン名・アイテム名で検索、「ふしぎなアメ」「ほしのすな」などで絞り込み）。手間に対して報酬が良いタスクを「👍 割に合う」としてハイライト（判定はこのアプリ独自の目安で、基準はページ内「判定のしかた」に記載）
- `shop.html`：ショップのボックス判定（ゲーム内ショップのボックスの値段と中身を入力すると、単品価格×重視度（レイドパス・リモートレイドパス＝最重要、スーパーふかそうち＝重要、その他＝おまけ、バッグ・ポケモンボックス拡張＝最優先）の合計と比べて S〜D で判定。日替わりで人によって違う場合があるため自動取得はせず手入力。単品価格は設定で変更でき、端末に保存）
- `ranks.html`：育成おすすめ TOP10（レイド〔総合・タイプ別〕／ジム攻撃／ジム防衛／連れ歩き）。各ポケモンに育成難易度も表示。PvPoke・PokeMiners・PokeAPI の公開データから `tools/build_rankings.py` が1日1回計算し、`data` ブランチの `rankings.json` に保存

## データについて
- イベント情報は有志サイト [LeekDuck](https://leekduck.com/events/) の内容を、[ScrapedDuck](https://github.com/bigfoott/ScrapedDuck)（LeekDuckから自動で取り出したJSON）経由で読み込んでいます。
- 英語のデータを、ポケモン名辞書（[PokeAPI](https://github.com/PokeAPI/pokeapi) のデータから作成）と置き換えルールで日本語にしています。公式の日本語イベント名とは違う場合や、英語のまま残る部分があります。
- 時刻は端末のタイムゾーンで表示します。データ上「現地時間」のイベントは端末の地域の時刻、UTC指定のもの（GOバトルリーグなど）は日本時間に直して表示します。

- ボーナス情報は `.github/workflows/bonuses.yml`（GitHub Actions、3時間ごと）が `tools/scrape_bonuses.py` で LeekDuck の各イベントページの「Bonuses」欄を集め、`data` ブランチの `bonuses.json` に保存しています。同じワークフローで `tools/scrape_research.py` が LeekDuck のリサーチ一覧を集めて `research.json` に保存します。Actions タブから手動実行もできます。

## 使い方
- `index.html` をブラウザで開くだけで動きます（インターネット接続が必要）。
- 公開ページ：https://shin632.github.io/pokego-today/ （スマホのブラウザで開いて「ホーム画面に追加」するとアプリのように使えます）

## ポケモン名辞書の更新（新しいポケモンが出たとき）
```sh
curl -sSLo names.csv https://raw.githubusercontent.com/PokeAPI/pokeapi/master/data/v2/csv/pokemon_species_names.csv
python3 tools/build_names.py names.csv names-ja.js
```
